# Сантехник Алматы — сайт частного мастера

Статический сайт (HTML + CSS + JS) для GitHub Pages.

- `index.html` — главная
- `zasor/`, `smesitel/`, `unitaz/`, `boiler/`, `avariya/` — посадочные страницы под Google Ads
- `img/` — видео первого экрана, фото «до/после», favicon, картинка для превью
- события для Google Ads: `call_click`, `whatsapp_click`, `form_submit` (dataLayer)

Код Google Tag Manager вставляется в `<head>` и после `<body>` (места отмечены комментариями).
